Detailed Description

PBR Material — shader + pipeline + parameters + texture bindings.

Encapsulates the full render state for a surface:

  • Shader programs (vertex + fragment)
  • GPU pipeline (rasterizer, depth, blend state)
  • Uniform data (PBR parameters)
  • Texture bindings (albedo, normal, metallic/roughness, AO, emissive)
