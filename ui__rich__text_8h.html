Detailed Description

BBCode parser for UIRichTextComponent.

Parses a BBCode markup string into a list of RichTextRun segments, each with uniform formatting (font, size, color, decoration, alignment).

This is a standalone parser — it does not render. The UISystem uses the parsed runs to draw text/image segments with the UIRenderer.
