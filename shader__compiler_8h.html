Detailed Description

Shader cross-compilation pipeline using glslang, SPIRV-Cross, and DXC.

Compiles GLSL 450 → SPIR-V via glslang, then optionally cross-compiles to HLSL, MSL, GLSL ES, or DXIL for multi-backend support.

Supported targets: SPIRV — Vulkan (native) HLSL — Direct3D 11 (SM 5.0 source) DXIL — Direct3D 12 (SM 6.0 bytecode, via DXC — Windows/XBOX only) MSL — Metal Shading Language 2.0 source GLSL_ES — GLSL ES 300 source (WebGL2 / mobile)
