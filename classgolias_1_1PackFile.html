Detailed Description

Read-only .gpak archive reader for cooked game resources.

GPAK binary format (written by tools/golias.py package): Header (20 bytes): "GPAK" magic + version(u32) + entry_count(u32) + toc_offset(u64) Data (variable): concatenated file blobs (optionally zstd-compressed) TOC (variable): per entry: path_len(u32), path(utf8), offset(u64), compressed_size(u64), original_size(u64), flags(u32)

Usage: PackFile pak; if (pak.Open("data.gpak")) { auto bytes = pak.Read("shaders/pbr.frag"); }
