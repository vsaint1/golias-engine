Detailed Description

Lightweight wrapper around an EnTT entity ID.

Provides component access: entity.AddComponent<Transform2D>(position); entity.GetComponent<SpriteRendererComponent>().color = Color::Red(); entity.HasComponent<Rigidbody2D>(); entity.RemoveComponent<BoxCollider2D>();
