Detailed Description

XML-based UI layout loader — define UIs in markup, script in C++.

Parses HTML-like XML files into Entity hierarchies with the engine's UI components (Canvas, RectTransform, Button, Text, InputField, etc.).

This dramatically improves developer experience compared to building entire UI trees in C++ procedural code.

Example XML layout:

<Canvas resolution="1280,720">
<Panel anchor="0,0,1,1" color="#1a1a2eFF">
<Text anchor="0.02,0.1,0.98,0.18" text="Hello Engine"
fontSize="32" color="#FFE699" alignment="center" />
<Button id="startBtn" anchor="0.35,0.4,0.65,0.48"
text="Start Game" fontSize="20" />
<InputField id="nameInput" anchor="0.3,0.55,0.7,0.62"
placeholder="Enter name..." fontSize="16" />
<Slider id="volumeSlider" anchor="0.3,0.7,0.7,0.74"
min="0" max="100" value="75" />
<CheckBox id="fullscreen" anchor="0.3,0.8,0.7,0.84"
label="Fullscreen" checked="false" />
<DropDown id="quality" anchor="0.3,0.88,0.7,0.94"
options="Low,Medium,High,Ultra" selected="2" />
</Panel>
</Canvas>

After loading, bind C++ callbacks:

UILayout layout;
layout.LoadFromFile(scene, "res://ui/main_menu.xml");
layout.Bind("startBtn", "onClick", [](){ StartGame(); });
layout.Bind("volumeSlider", "onValueChanged", [](float v){ SetVolume(v); });
layout.Bind("nameInput", "onEndEdit", [](const String& s){ SetPlayerName(s); });
