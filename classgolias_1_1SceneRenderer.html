Detailed Description

Forward+ 3D renderer with PBR shading and multi-pass pipeline.

Usage: renderer.Initialize(device); // Each frame: renderer.BeginFrame(cmd, camera, transform, width, height); renderer.Submit(mesh, material, modelMatrix); renderer.SubmitLight(light, lightTransform); renderer.EndFrame();
