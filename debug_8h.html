Detailed Description

Engine-grade debug utilities — structured, channel-based logging via spdlog.

Log channels map directly to engine subsystems: LogCore — engine core, application, file system, assets, tasks LogRenderer — RHI device, scene renderer, shaders, post-process, shadows LogInput — keyboard, mouse, gamepad, action bindings LogAudio — audio manager, clips, sources, listener LogPhysics — physics world, bodies, constraints, character controllers LogScene — scene lifecycle, entities, serialization, prefabs

Log level semantics: Trace — per-frame internals, extremely verbose (compile-stripped in Release) Debug — diagnostic details, enabled in Debug builds only Info — normal operational events: init, shutdown, resource loads Warning — unexpected but recoverable conditions Error — operation failed; execution continues with degraded state Critical — fatal failure; engine cannot continue (triggers Assert abort)

Usage: Debug::Log(LogCore, "Engine initialized in {}ms", elapsed); Debug::LogWarning(LogRenderer, "Shader '{}' missing uniform '{}'", name, uniform); Debug::LogError(LogAudio, "Failed to open device: {}", err); Debug::LogDebug(LogPhysics, "Body created at ({:.2f}, {:.2f}, {:.2f})", x, y, z); Debug::LogTrace(LogCore, "Frame {} — dt={:.4f}ms", frame, dt * 1000.f); Debug::Assert(handle != nullptr, LogRenderer, "RHI handle must not be null");
