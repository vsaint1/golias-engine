Detailed Description

Singleton engine core — manages all subsystems and the main loop.

Subsystems: GPU device, 3D renderer, shader compiler, physics, input, filesystem.

Architecture: Engine Core → Platform (SDL3) → RHI → Renderer → Scene (EnTT) → Physics (Bullet3D)
