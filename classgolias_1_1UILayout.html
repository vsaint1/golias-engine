Detailed Description

Loads UI layouts from XML files and creates Entity hierarchies.

Workflow:

  1. Call LoadFromFile() or LoadFromString() to parse XML and create entities
  2. Call Bind() to attach C++ callbacks to named elements
  3. Call FindById() to get entity handles for dynamic updates

The loader creates proper parent-child hierarchies with HierarchyComponent and sets up all UI components (RectTransform, UIImage, UIText, UIButton, etc.) based on element attributes.
