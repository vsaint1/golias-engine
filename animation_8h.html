Detailed Description

Skeletal animation system — bones, clips, blending, GPU skinning.

Supports:

  • Bone hierarchy with offset matrices
  • Animation clips with position/rotation/scale keyframes
  • Linear interpolation between keyframes
  • Animation blending (crossfade)
  • Per-entity AnimatorComponent for ECS integration
