Detailed Description

Rich text component — BBCode markup rendered as multi-styled text with inline images.

Supported BBCode tags: [b]bold[/b] [i]italic[/i] [u]underline[/u] [s]strikethrough[/s] [color=#RRGGBB]...[/color] [color=red]...[/color] [font_size=20]...[/font_size] [font=path/to/font.ttf]...[/font] [center]...[/center] [right]...[/right] [left]...[/left] [img]path[/img] [img=64x64]path[/img] [img=64x64,0,0,0.5,0.5]path[/img] [indent]...[/indent]

Example: "[b]Hello[/b] [color=#FF0000]World[/color]! [img=32x32]res://icons/star.png[/img]"
