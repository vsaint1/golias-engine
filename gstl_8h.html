Detailed Description

Engine STL wrappers — HashMap, List, CString, String, and common containers.

All engine and game code should use these types instead of raw STL types. The underlying implementations (std::unordered_map, std::vector, etc.) are implementation details that can be swapped for custom allocators or alternative containers in the future.

Types: String — owning, mutable string (wraps std::string) CString — non-owning string view (wraps std::string_view) HashMap — hash map (wraps std::unordered_map) List — dynamic array (wraps std::vector) Pair — key-value pair (wraps std::pair) Optional — optional value (wraps std::optional) Array — fixed-size array (wraps std::array) Set — hash set (wraps std::unordered_set)
