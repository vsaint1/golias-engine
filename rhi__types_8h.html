Detailed Description

Backend-agnostic RHI type definitions.

All enums, handle types, descriptor structs, and device capability structures used by the abstract RHI layer. No backend-specific includes.

Backends: SDL_GPU (Vulkan/D3D12/Metal), GLES3 (OpenGL ES 3.0 / WebGL 2.0 / Desktop GL 3.3+)
