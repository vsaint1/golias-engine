Detailed Description

GPU-resident 3D mesh with sub-mesh support.

Stores vertex and index data on the GPU via RHI handles. Supports multiple sub-meshes for multi-material objects.

Usage: auto mesh = Mesh::LoadFromFile(device, "res/models/suzanne/suzanne.obj"); // or procedural: auto cube = Mesh::CreateCube(device); auto sphere = Mesh::CreateSphere(device, 1.0f, 32, 32);
