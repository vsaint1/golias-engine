Detailed Description

UITheme serialization — load/save .gtheme JSON files.

.gtheme is a JSON file that defines a complete UITheme (colors, sizes, fonts, textures). Example:

{
"cornerRadius": 6.0,
"borderWidth": 1.0,
"textColor": [1, 1, 1, 1],
"backgroundColor": [0.16, 0.16, 0.21, 1],
"fontSize": 14.0,
"font": "res://fonts/NotoSans-Regular.ttf",
"button": {
"normal": [0.25, 0.25, 0.3, 1],
"hovered": [0.3, 0.3, 0.38, 1],
"pressed": [0.18, 0.18, 0.25, 1],
"disabled": [0.2, 0.2, 0.2, 0.5],
"cornerRadius": 4.0
},
...
}
