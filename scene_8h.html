Scene management — container for entities, systems, and behaviors.

Architecture overview:

Scene ├── Entity / Component registry (EnTT) ├── System registry — ISystem subclasses for shared logic │ scene.AddSystem<MySystem>(); ├── NativeBehavior — per-entity C++ scripts │ scene.AddBehavior<FreeFlyCamera>(cameraEntity); └── Physics world — Bullet3D fixed-step simulation

System call order per frame: OnPhysicsUpdate → [Physics step] → OnUpdate → OnRender
