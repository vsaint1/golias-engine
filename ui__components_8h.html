Detailed Description

UI ECS components — Canvas, RectTransform, Button, Image, Text, InputField, Slider, CheckBox, DropDown, ScrollView, and a global UITheme.

All UI components are plain structs that attach to entities in the EnTT registry. The UISystem processes these components each frame to layout, render, and handle interaction.

The UITheme provides global visual defaults (colors, corner radii, sizes, custom textures). Each widget may override specific theme values via per-component fields. A value of -1.0f for cornerRadius means "inherit from theme".

Typical hierarchy: Canvas (entity) └─ Panel (RectTransform + UIImage) ├─ Title (RectTransform + UIText) ├─ Button (RectTransform + UIButton + UIImage + UIText child) └─ InputField (RectTransform + UIInputField)
