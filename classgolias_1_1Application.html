Detailed Description

Base class for game applications.

Users override Initialize(), Update(), and Destroy() to implement game logic. The engine handles window creation, GPU device setup, and the main loop.

Usage: class MyGame : public golias::Application { public: MyGame() : Application(ApplicationConfig()) { mConfiguration.window.width = 1280; mConfiguration.window.height = 720; mConfiguration.backend = RHIBackend::Compatibility; mConfiguration.debugMode = false; } bool Initialize() override { ... } void Update(float dt) override { ... } void Destroy() override { ... } };
