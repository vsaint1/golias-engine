Detailed Description

3D Shader Contract — binding conventions, UBO layouts, and built-in shaders

Defines the built-in uniforms, vertex layout, and binding conventions for the Golias 3D PBR rendering pipeline.

SPIR-V Binding Convention (SDL_GPU): set=0: Vertex samplers / storage textures / storage buffers set=1: Vertex uniform buffers set=2: Fragment samplers / storage textures / storage buffers set=3: Fragment uniform buffers
